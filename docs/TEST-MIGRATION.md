# Test migration

This matrix starts from the baseline dashboard tests at `90a8847` and the current repository tests. The rebuild replaces image-scene assertions with evidence from the actual WebGL 2 world. **Implemented** means that the current unit, contract, or browser spec contains the assertions; it does not claim that the current worktree has a fresh passing run. A row marked **pending** still needs the appropriate fresh run. CPU/WASM and source evidence do not substitute for browser evidence, and focused browser passes do not substitute for the full Chromium and Firefox suite.

The browser setup matrix is deliberately narrower than the campaign configuration matrix: `tests/onboarding.spec.ts` exercises all three trails and all three supply presets, with the helper defaults of era `1848` and occupation `banker`; its additional occupation case exercises `farmer`. The full legal trail/era/occupation combinations remain CPU/WASM configuration evidence and are not nine-occupation/four-era UI coverage.

The strict test/config type check is `npm run test:types` (`tsc -p tsconfig.tests.json`). Asset and license verification is `npm run test:assets`; it checks the local manifest, copied notices, runtime paths, and rejects runtime HTTP(S) hotlinks.

The historical dashboard specs are preserved under [`docs/archive/browser-tests/`](archive/browser-tests/). Do not treat archived assertions, screenshots, or the old demo as proof of the 3D runtime contract.
